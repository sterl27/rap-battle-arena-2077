**Rap Battle Arena 2077** is a next-gen, AI-driven rap battle simulator where your lyrics are judged by a neural intelligence in real-time. Battle against the legendary "Cyber-Shogun" in a 3D arena that reacts to your flow, rhythm, and momentum.

---

## 🦾 Key Features

### 🎧 AI Neural Scoring Engine
Every bar you drop is analyzed by the **Gemini AI Engine**. The system evaluates:
*   **Rhyme Complexity**: From simple rhymes to technical multis.
*   **Punchline Impact**: The raw energy and wit behind your words.
*   **Flow Consistency**: How well your bars synchronize with the beat.
*   **Neural Commentary**: Get instant, cynical technical feedback from the arena's AI commentator.

### 🌌 Reactive Holographic Arena
*   **Audio-Reactive Shaders**: Avatars and envrionment elements pulse, glitch, and scale in real-time based on the Web Audio API frequency data.
*   **Dynamic Momentum**: As the battle intensity rises, the environment shifts color and the "Glitch Intensity" increases.
*   **Cinematic Camera**: A procedural camera system that tracks the action and pulses with the kick drum.

### 🥁 Evolving Soundscapes
*   **Momentum-Based Synthesis**: The beat isn't just a loop. As you build momentum, the bass synth gets grittier, and additional percussion layers are triggered.
*   **Procedural Crowd**: Perform a critical strike to hear the digital crowd roar in approval.

## 🚀 Getting Started

### Prerequisites
*   [Node.js](https://nodejs.org/) (v18 or higher)
*   A Google Gemini API Key

### Installation

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/sterl27/rap-battle-arena-2077.git
    cd rap-battle-arena-2077
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Environment Setup**
    Create a `.env.local` file in the root directory and add your key:
    ```env
    VITE_GEMINI_API_KEY=your_api_key_here
    ```

4.  **Ignite the Arena**
    ```bash
    npm run dev
    ```

## 🕹️ Strategy Guide

*   **The Editor**: Type your lyrics in the terminal-style editor.
*   **AI Sync**: If your neural link is slipping, click **"AI GENERATOR"** to have the system suggest high-tier technical bars.
*   **Momentum**: The higher your momentum, the faster you drain the opponent's Hype. Keep the pressure on.
*   **Critical Strikes**: High-scoring AI bars (90+) trigger **Critical Strikes**, dealing massive damage and silencing the opposition.
